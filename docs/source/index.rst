GenoKit documentation
=====================

GenoKit is an open-source Python command-line toolkit connecting genome
annotations with sequence extraction, oligonucleotide design and visualization.
These pages describe the **1.0.0 source implementation**. A published package
may expose different options; check ``GenoKit --version`` and command help.

Start with :doc:`install` and :doc:`tutorial`. The :doc:`example` page includes
a small downloadable genome and annotation that can be used without human data.
For a complete list of flags and defaults, see :doc:`command_reference`.
